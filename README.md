# RAG-агент для базы знаний Lamoda

Агент отвечает на вопросы продавцов по статьям [академии селлеров Lamoda](https://academy.lamoda.ru/). Поиск и агент написаны с нуля, без LangChain и векторных баз.

## Как устроено

1. Парсер асинхронно обходит сайт (httpx + asyncio) и сохраняет текст статей в Markdown. Если страница не открылась, обход продолжается. Получается около 336 статей.
2. Ретривер режет статьи на чанки (~2300) и ищет по ним двумя способами: BM25 с лемматизацией через pymorphy3 и эмбеддинги multilingual-e5. Два списка объединяются через Reciprocal Rank Fusion.
3. Агент работает по схеме ReAct на Groq (Llama 3.3 70B): думает, вызывает поиск, отвечает. В ответе только то, что нашлось в базе, со ссылками на статьи. Если ответа в базе нет, агент так и говорит.

BM25 хорошо находит точные термины и названия, эмбеддинги находят перефразированные вопросы. RRF удобен тем, что объединяет ранги, и не нужно подбирать веса и нормировать скоры.

Подробнее про решения и тесты на краевых случаях: [DESIGN.md](DESIGN.md).

## Файлы

- `lamoda_seller_agent.ipynb` — весь пайплайн в одном ноутбуке
- `parser.ipynb` — только парсер
- `retriever.ipynb` — ретривер и агент

## Запуск

1. Открыть `lamoda_seller_agent.ipynb` в Colab. GPU не обязателен, но с ним эмбеддинги считаются быстрее.
2. Взять бесплатный ключ на [console.groq.com](https://console.groq.com) и положить в `GROQ_API_KEY` (или ввести, когда ноутбук попросит).
3. Run all. Парсер заново соберёт статьи в `data/`.
